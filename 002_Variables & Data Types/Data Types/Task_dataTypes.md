# Python Data Types - Student Management Tasks

## Objective

Build a **Student Management System** while learning every Python data
type through real-world tasks.

------------------------------------------------------------------------

# Task 1 - Student Registration

## Requirement

The college wants to register a new student.

### Scenario

Store a student's basic information.

### Concepts Used

-   Variables
-   int
-   str
-   float
-   bool
-   print()

### Expected Fields

-   Student ID
-   Student Name
-   Age
-   Department
-   CGPA
-   Passed Status
